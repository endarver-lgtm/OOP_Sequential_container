# Лабораторная работа №3: Последовательные контейнеры STL

## Описание проекта
Проект представляет собой реализацию консольного программного комплекса для учета, диспетчеризации и мониторинга парка строительной техники строительной компании (Вариант 10). Работа демонстрирует практическое применение стандартных последовательных контейнеров STL C++ (`std::vector`, `std::list`, `std::array`), алгоритмов сортировки, поиска и фильтрации данных, а также принципов объектно-ориентированного программирования (наследование, полиморфизм, инкапсуляция).

## Цели и задачи работы
- Освоение принципов работы со стандартными последовательными контейнерами STL: `std::vector`, `std::list`, `std::array`.
- Организация полиморфного хранения объектов производных классов в динамических коллекциях.
- Реализация алгоритмов поиска, фильтрации и многокритериальной сортировки с применением лямбда-выражений и предикатов.
- Разработка удобного модульного интерфейса управления данными с защитой от некорректного пользовательского ввода.
- Обеспечение экспорта и импорта данных для долговременного хранения.

## Предметная область: Учет строительной техники (Вариант 10)
Система автоматизирует управление парком тяжелой техники, распределение машин по строительным объектам и учет штатных операторов:
- Учет разнородных типов техники (экскаваторы, автокраны) с персональными техническими характеристиками.
- Формирование нарядов на выполнение работ с фиксацией дат, объектов и автоматическим расчетом стоимости аренды.
- Ведение квалификационного реестра операторов (машинистов) с привязкой к конкретным единицам парка.

## Архитектура и основные классы

### Иерархия строительной техники
- `Equipment` - абстрактный базовый класс единицы техники. Содержит идентификатор (ID), наименование модели, регистрационный номер, базовую почасовую ставку аренды, текущий статус (в работе, на обслуживании, свободен) и указатель на закрепленного машиниста. Предоставляет чисто виртуальные интерфейсы для вывода информации, клонирования и расчета стоимости рабочей смены.
- `Excavator` - класс экскаватора, наследующий `Equipment`. Дополнительно содержит специализированную характеристику: объем ковша в кубических метрах, учитываемый при планировании земляных работ.
- `Crane` - класс грузоподъемного крана, наследующий `Equipment`. Расширен параметром максимальной грузоподъемности (в тоннах), определяющим доступность техники для монтажных задач.

### Сопутствующие сущности
- `Operator` - учетная карточка машиниста/оператора: идентификационный номер, ФИО, категория водительского удостоверения, стаж работы (в годах) и контактный номер телефона.
- `WorkAssignment` - наряд на производство работ: идентификатор наряда, наименование строительного объекта, указатель на задействованную технику, интервал дат проведения работ, а также метод вычисления итоговой финансовой стоимости наряда.

### Менеджер парка техники (`CompanyFleet`)
Центральный управляющий класс, инкапсулирующий коллекции STL и бизнес-логику системы:
- `std::vector<Equipment*> fleet_` - динамический массив для хранения полиморфного парка машин. Обеспечивает произвольный доступ по индексу за O(1), динамическое расширение и возможность эффективной сортировки.
- `std::list<WorkAssignment> assignments_` - двусвязный список для ведения непрерывного журнала нарядов на работы. Гарантирует эффективную вставку и удаление записей в произвольной позиции без реаллокации и с сохранением валидности итераторов.
- `std::array<Operator, 5> operators_` - статический массив фиксированного размера под квалификационный штат сертифицированных операторов компании.

## Функциональные возможности программы
- Управление парком машин: добавление экскаваторов и автокранов с валидацией характеристик, удаление по ID, просмотр сводной таблицы парка.
- Поиск и фильтрация: многопараметрический регистронезависимый поиск техники по фрагменту названия модели или регистрационному знаку; фильтрация по типу механизма (экскаватор / кран).
- Сортировка: упорядочивание парка по почасовой стоимости аренды (по возрастанию / убыванию) и по алфавиту моделей.
- Журнал нарядов: добавление наряда с привязкой машины к объекту, расчет совокупной стоимости смены, сортировка нарядов по стоимости и коду, фильтрация по объекту.
- Учет операторов: назначение машинистов в штатные слоты, сортировка по трудовому стажу, поиск по имени и идентификатору.
- Файловый ввод-вывод: сохранение таблиц парка, журнала нарядов и штата операторов в текстовые файлы отчетов.
